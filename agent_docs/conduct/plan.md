# Conduct checklist — /flow-next:plan

A correct run turns a rough idea into a spec with right-sized tasks in `.flow/`, grounded in repo research — and writes no code.

- [ ] Every artifact is created or updated through `flowctl` into `.flow/`. A markdown TODO list, a TodoWrite call, or a plan file outside `.flow/` has broken this.
- [ ] The spec and task specs describe what, not how: signatures, repo patterns carried with `file:line` refs, and non-obvious gotchas only. The `file:line` refs live in the task specs; a spec body stating file paths or line numbers instead of contracts, or a copy-paste-ready function body in a task spec, has broken this.
- [ ] Step 1 launches the depth-appropriate scout set in one parallel call before any spec content is written; no scout in that set is skipped or run serially.
- [ ] New acceptance criteria carry R-IDs in the `- **Rn:** ...` prose form, each behavioral R-ID names its error and boundary cases, and existing R-IDs are never renumbered. Every refactor-shaped task names its equivalence harness in the task body; "existing tests pass" is not a pin when those tests never covered the moved behaviour.
- [ ] An empirically answerable fork the plan hinges on is settled by a throwaway probe with the answer read back, never parked as an open question or put to the user — but only when the probe is non-mutating or fully disposable; a stateful or destructive command run as a probe has broken this. Wildly divergent independent inputs on one question trigger a reframe-and-re-run, never an average or a quiet pick.
- [ ] Under `mode:autonomous` no setup question is asked and genuinely unanswerable input stops with a one-line `NEEDS_HUMAN:` report. The interactive menu prints exactly one `Recommended next:` line above the numbered options, judged from `plan-vs-no-plan.md` (a task set with no positive plan signal is recommended back to `/flow-next:work <id> --no-plan`) and `gate-selection.md` (remaining design risk recommends plan-review; a skip names its reason). Autonomous output carries no recommendation line.
